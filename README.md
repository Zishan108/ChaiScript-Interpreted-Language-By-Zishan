# ChaiScript

Welcome to **ChaiScript**, a Chai-themed programming language inspired by Python and JavaScript. This language integrates several built-in data structures, such as Lists, Strings, Numbers, and more, while maintaining a simple and elegant syntax.

**Created by:** Zishan , 19 years old (05 November, 2024)

## Inspiration

ChaiScript is inspired by the rich culture of tea and the elegance of Python. The only thing which fits best with coding is chai so why not a chai-themed programming language?The goal was to create a programming language that is as enjoyable to use as sipping a cup of chai, making programming a delightful experience.

## Features

- **Simple Syntax:** Easy to read and write, ideal for beginners.
- **Built-in Data Structures:** Includes Lists (ArrayList), Strings and more
- **Dynamic Typing:** Automatically determine variable types at runtime.
- **Comprehensive Standard Library:** Functions for mathematical operations, string manipulation, system util and more

## Getting Started

To get started with ChaiScript, follow these steps:

1. **Download the ChaiScript Package:**
   - Download the ChaiScript package from [here](https://drive.google.com/uc?export=download&id=13BKOA-Y9YtFsOW5lTPOhBrMCHHPLIzO5
   ).

2. **Extract the Package:**
   - Extract the downloaded package to your desired location.

3. **Run the ChaiScript Terminal:**
   - Navigate to the extracted folder.
   - Run `ChaiScript Terminal.exe` to start the ChaiScript interpreter.

4. **Write Your Code:**
   - Create a new file with the `.chai` extension inside the folder where your ChaiScript Terminal is and write your ChaiScript code.

5. **Execute Your Code:**
   - In the shell, use the `run()` command followed by the file name to execute your code.
   - Example: `run("my_script.chai")`

## Built-in Functions

ChaiScript comes with a variety of built-in functions for common tasks. Here are a few examples:

- `serveChai(value)`: Outputs the value to the console.
- `orderChai(prompt)`: Prompts the user for input.
- `len(list)`: Returns the length of the list.
